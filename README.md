# TaskSprite Releases

This public repository contains binary release artifacts for TaskSprite. It does not contain the TaskSprite source code or project history.

## Verification

- Verify installer downloads against SHA256SUMS.txt.
- In-app updates are verified with the Tauri updater signature published with each release.
- Current installers are not Authenticode-signed and Windows may display an Unknown publisher or SmartScreen warning.
